# DayKey Lesson Jump

Local VS Code/Cursor extension for navigating DayKey lessons across files.

## Commands

- `DayKey: Next Lesson`
- `DayKey: Previous Lesson`

## Default keys inside the DayKey workspace

- `Alt+N` moves to the next lesson
- `Alt+P` moves to the previous lesson

These keys only activate when the current workspace is the DayKey repository.

## Install

1. Package the extension as a VSIX.
2. In Cursor or VS Code, run `Extensions: Install from VSIX...`.
3. Choose the generated `.vsix` file from this folder.
